# 🏃‍♂️ Calorie-to-Route Runner (rush_calory)

Интерактивное веб-приложение: **«Умный генератор беговых маршрутов по калориям и погоде»** на стеке **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Leaflet** и **OSRM**.

---

## ⚡ Ключевые возможности

1. **Математика калорий в дистанцию:**
   - Формула: `Дистанция (км) = Калории / (Вес_кг * 1.036)`
   - Пресеты: *Сникерс (~250 ккал), Круассан (~350 ккал), Бургер (~550 ккал), Пицца (~720 ккал), Донат (~300 ккал)*.
   - Слайдер точной настройки и выбор темпа бега.
2. **Строгая проверка Geolocation API:**
   - Опция `enableHighAccuracy: true`.
   - Проверка точности: если погрешность хуже 60м, выводится информационный экран с рекомендациями.
3. **Погодный радар (Live Weather via Open-Meteo):**
   - Температура, скорость ветра, вероятность дождя в ближайшие 2 часа и статус пригодности для бега.
4. **Генерация кольцевого маршрута (OSRM Foot Routing):**
   - Алгоритм создания замкнутой петли с возвратом в точку старта.
   - Разметка километровых отметок (1k, 2k, 3k...).
   - Смена направления петли («Другая петля») и экспорт в **GPX** для часов Garmin / Apple Watch / Strava.
5. **Фильтр «Через парки и зелёные зоны»:**
   - Приоритет пешеходных аллей, скверов и набережных.
6. **Режим активного трекинга (Live Run HUD):**
   - `navigator.geolocation.watchPosition` в реальном времени.
   - Спидометр (км/ч), счётчик сожжённых калорий, оставшаяся дистанция, секундомер и симулятор движения.
7. **Мобильная адаптация:**
   - Эргономичная нижняя шторка (Bottom Sheet) в стиле Apple Maps / Strava.

```bash
# Запуск dev-сервера

```
